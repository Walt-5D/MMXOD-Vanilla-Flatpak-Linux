<summary><b>🇺🇸 English Instruction</b></summary>
<br>

### 1. Game Files Location
All configurable game files and user assets are located directly in your Documents folder:

`~/Documents/MMXOD/`

> **Note:** This folder is visible directly in your home directory, so no hidden folder configuration is required.

### 2. Connect to a Server by IP (`region.txt`)
To change servers or connect to a custom IP address:

1. Open your file manager and navigate to:
   `~/Documents/MMXOD/`
2. Open the `region.txt` file with any text editor.
3. Replace the text with the IP address or domain of the server you want to join.
4. Save the file and restart the game.

### 3. Add Custom Maps (`maps_custom`)
To install community-made maps:

1. Download the custom map files.
2. Navigate to the maps directory:
   `~/Documents/MMXOD/assets/maps_custom/`
3. Copy the map files into that folder.
4. Launch the game; the new stages will appear in the stage selection menu.

<br>

### 1. Ubicación de los Archivos del Juego
Todos los archivos configurables y recursos del juego se encuentran ubicados directamente en tu carpeta de Documentos:

`~/Documentos/MMXOD/`

> **Nota:** Esta carpeta es visible directamente desde tu explorador de archivos sin necesidad de mostrar carpetas ocultas.

### 2. Conectarse a un Servidor por IP (`region.txt`)
Para cambiar de servidor o conectarte a una IP personalizada:

1. Abre tu gestor de archivos y navega a:
   `~/Documentos/MMXOD/`
2. Abre el archivo `region.txt` con un editor de texto.
3. Reemplaza el texto por la dirección IP o dominio del servidor al que deseas unirte.
4. Guarda el archivo y reinicia el juego.

### 3. Agregar Mapas Personalizados (`maps_custom`)
Para instalar escenarios creados por la comunidad:

1. Descarga los archivos del mapa personalizado.
2. Navega al directorio de mapas:
   `~/Documentos/MMXOD/assets/maps_custom/`
3. Copia los archivos del mapa dentro de esa carpeta.
4. Inicia el juego; los nuevos escenarios aparecerán en el menú de selección de mapas.
